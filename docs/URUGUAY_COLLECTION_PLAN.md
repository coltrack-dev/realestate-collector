# Uruguay collection expansion plan

Статус: механизм подготовлен, массовый live-import заблокирован до явного
подтверждения условий владельца Gallito.

## Почему импорт 50/200/500 не запускался

Публичный MCP предоставляет unauthenticated `search_listings`,
`more_results` и `get_listing`, но найденная документация не подтверждает:

- допустимый объём автоматизированного извлечения за сутки/месяц;
- разрешение на регулярное агрегирование результатов в собственной базе;
- срок хранения цен и истории изменений;
- разрешение на хранение внешних URL фотографий и их повторное отображение;
- порядок использования MCP для фоновых, неинтерактивных задач.

MCP также ограничивает одну выдачу 10 результатами и до 10 страницами; каждый
поиск учитывается в quota. Поэтому публичный доступ не трактуется как blanket
permission для массового каталога.

## Вопросы владельцу Gallito

1. Разрешён ли автоматизированный read-only сбор через public MCP без
   присутствия пользователя?
2. Каковы разрешённые requests/day, searches/day и pages/search для фоновой
   синхронизации?
3. Разрешены ли 200–500 объявлений за один цикл и какая минимальная частота
   обновления допустима?
4. Можно ли хранить `external_id`, title, description, price, currency,
   characteristics и price history? Каков retention TTL?
5. Можно ли хранить и повторно показывать внешние URL фотографий? Разрешено ли
   скачивание или только hotlink?
6. Нужно ли удалять/анонимизировать записи после исчезновения объявления?
7. Есть ли официальный batch/export/feed для партнёрской интеграции вместо
   MCP search quota?
8. Разрешены ли `more_results` для периодического импорта, а не только для
   ответа пользователю в интерактивном ассистенте?

До получения ответа используется только dry-run, fixtures и уже выполненный
ограниченный импорт 10 объявлений.

## Подготовленные задания

Collector поддерживает комбинации региона, операции и типа объекта:

- регионы: Montevideo, Maldonado, Punta del Este, Canelones, Ciudad de la
  Costa, Colonia del Sacramento, Piriápolis;
- операции: `sale`, `rent`;
- типы: `apartment`, `house`, `land`, `commercial`.

Пример команды после получения разрешения:

```bash
go run ./cmd/collector \
  -source=gallito -country=UY -max-listings=50 -max-pages=10 \
  -operation=sale,rent -property=apartment,house,land,commercial \
  -progress-file=var/gallito-progress.json
```

`-resume` продолжает сохранённые `searchId/page`, а progress file также хранит
уже увиденные external IDs для дедупликации между заданиями. Collector никогда
не вызывает `get_listing` во время Summary import.

## Другие кандидаты

- Gallito REST API требует регистрации и User Key; его планы публикуют
  лимиты, но не являются разрешением для нашего проекта без регистрации и
  договора.
- `api.nai.com.uy` описывает JSON feed, но требует ключ конкретной inmobiliaria;
  это не открытый общий каталог.
- Agentiz XML feed предназначен для агентств, публикующих собственный feed из
  личного кабинета, а не для свободного агрегирования чужого каталога.
- Mercado Libre требует зарегистрированное приложение/OAuth; anonymous
  регулярный импорт не подтверждён.
