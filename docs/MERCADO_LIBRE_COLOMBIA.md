# Mercado Libre Colombia: проверка источника объявлений

Дата проверки: 2026-11-08

## Результат

Mercado Libre предоставляет официальный API для поиска и получения карточек
items. Недвижимость присутствует среди поддерживаемых типов/категорий
публикации. Это потенциально разрешённый API-источник, но он не был подключён
к проекту: не создано приложение, не получены credentials и не проверены
условия хранения данных для конкретного сценария мониторинга.

Официальные материалы:

- [Mercado Libre Developers Colombia](https://developers.mercadolibre.com.co/)
- [Items and searches API](https://developers.mercadolibre.com.co/en_us/items-and-searches)
- [Real estate API guidance](https://developers.mercadolibre.com.co/en_us/real-estate)
- [Notifications](https://developers.mercadolibre.com.co/en_us/notifications)

## Проверка требований

| Вопрос | Результат |
|---|---|
| Есть ли категория недвижимости? | Да, платформа документирует публикацию и работу с объектами недвижимости; фактический category ID для Colombia нужно получить через API и зафиксировать в тестовой конфигурации. |
| Есть ли официальный API поиска? | Да. Search API возвращает активные items, а `/items/{ITEM_ID}` — детальную карточку. |
| Доступен ли анонимный доступ? | Нельзя считать его гарантированным. Некоторые публичные endpoints могут отвечать без пользовательской авторизации, но приложение не должно строить регулярный импорт на непроверенном anonymous-доступе. Проверка должна выполняться тестовым приложением в рамках документации API. |
| Нужен ли OAuth? | Для приложения и защищённых операций требуется access token. Google OAuth не используется и не нужен; это собственная авторизация Mercado Libre. |
| Лимиты | Search API использует пагинацию и ограничение размера страницы; в документации для больших выборок также описаны ограничения сканирования. Точный лимит нужно читать из текущих response headers и условий приложения, а не зашивать без проверки. |
| Срок хранения | Универсальный срок хранения карточек, изображений и истории цен в рамках этого исследования не подтверждён. Перед импортом нужно проверить Developer/API Terms и ограничения на кэширование, повторное использование и удаление данных. |
| Мониторинг цен | Технически возможен по стабильному `ITEM_ID`: notifications для событий и периодический GET карточки как reconciliation. Право формировать длительную историю цен должно быть отдельно подтверждено условиями API. |

## Поля и идентификация

Карточка item обычно предоставляет ID, permalink, заголовок, цену и валюту,
изображения, характеристики, категорию и сведения о локации. Для адаптера
нужно сохранять `source=mercadolibre-co` и оригинальный `ITEM_ID` в
`external_id`; цену записывать без конвертации и вместе с валютой.

Недостаточно полагаться на текстовый адрес или заголовок. Смена цены должна
приводить к новому snapshot только после успешного получения карточки и
проверки, что item относится к разрешённой категории недвижимости.

## Решение для проекта

Mercado Libre остаётся вторым кандидатом после Wasi. Реализация адаптера
отложена до получения:

1. подтверждённого developer account/app;
2. разрешённых scope и access token для Colombia;
3. ответа владельца/условий API о хранении истории и изображений;
4. тестовых JSON-ответов, которые можно сохранить как фикстуры без секретов;
5. подтверждённых rate limits, pagination и notification semantics.

До этого проект не заявляет live-импорт Mercado Libre и не выполняет массовые
запросы.
